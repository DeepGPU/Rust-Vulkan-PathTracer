[Vulkan based Ai framework 프로젝트 및 팀원 소개]

안녕하세요.

저희는 C++과 Vulkan만을 사용해 AI 프레임워크를 직접 개발하고 있는 프로젝트 팀입니다. 현재 직장인과 휴식 중인 개발자분들을 포함해 총 6명이 지난 반년간 꾸준히 열정을 쏟고 있습니다. 기본적인 구조는 어느 정도 갖춰졌지만, 실전에 투입 가능한 수준의 프레임워크를 완성하기 위해서는 추가해야 할 기능과 최적화 요소들이 아직 많습니다. 이에 따라 현재 함께할 개발자분을 모집하고 있습니다.

Vulkan은 그래픽·컴퓨트 모두를 아우르는 저수준 GPGPU API로, 현존 GPU API 가운데 단언컨대 난이도가 가장 높습니다. 생산성은 낮고, 성능을 제대로 끌어내려면 고려해야 할 지점이 끝없이 이어집니다. 그래서 다수의 AI 프레임워크가 Vulkan을 백엔드로 채택하지 않는 현실적인 이유가 있습니다.

그럼에도 Vulkan은 GPU 스케줄링·메모리 정책까지 미세하게 직접 제어할 수 있습니다. 이 폭넓은 제어권을 제대로 활용하면 다른 GPU API 대비 더 높은 성능을 뽑아낼 잠재력이 있습니다. 다만 이 점이 곧바로 ‘장점’으로 직결되는 것은 아닙니다. 극악의 사용 난이도와 저수준 성능 튜닝을 서로 맞바꾸는, 일종의 ‘등가교환’이기 때문입니다. 즉, 쉽지 않지만, 해내면 분명한 보상이 존재합니다.

Vulkan의 진정한 강점은 모든 플랫폼과 GPU 제조사에서 최상위 수준의 드라이버 최적화가 보장된다는 점입니다. 게임 시장은 모든 GPU 업체가 사활을 거는 영역이며, Vulkan은 최신 게임에서 핵심 역할을 담당합니다. 엔비디아가 CUDA를 키우기 위해 OpenCL 지원을 소홀히 했던 과거와 달리, Vulkan을 홀대하는 것은 곧 경쟁사에게 게임 시장을 통째로 넘겨주는 것과 같습니다. 따라서 GPU 제조사들은 향후에도 계속해서 Vulkan 드라이버를 적극적으로 최적화할 수밖에 없습니다. 결론적으로, 멀티 플랫폼·멀티 벤더를 단일 API로 아우르는 유일한 현실적 해법이 지금 시점에는 Vulkan입니다.

물론, 가장 큰 진입 장벽은 난이도와 낮은 코드 생산성입니다. 저희는 이를 상쇄하기 위해 자체 Vulkan 프레임워크를 구축해, 개발자가 Vulkan을 깊게 몰라도 AI 프레임워크 개발에 참여할 수 있도록 만들었습니다. 다만 프로젝트 특성상 GPU 프로그래밍에 대한 이해와 중급 이상 C++ 숙련도는 필요합니다.

이 프로젝트에 참여하시면, AI 개발의 A부터 Z까지—저수준 GPGPU 최적화(MatMul 튜닝 등)부터 대규모 모델(LLM) 학습까지—전체 흐름을 파이썬 없이 온전히 C++ 기반에서 경험하실 수 있습니다.

저희는 어렵고 험난하지만, 동시에 깊이 있고 흥미진진한 이 사이드 프로젝트에 함께 도전할 열정적인 개발자를 기다리고 있습니다. AI와 GPU를 진짜로 이해하고 싶은 분이라면, 많은 것을 얻어가실 수 있습니다.
